# V6 ASMR AI — Android

Versione 6 del progetto: app Android per creare prompt/video ASMR con workflow a più agenti.

## Struttura
- `app/` — modulo Android
- `gradle/` — wrapper Gradle
- `settings.gradle`
- `build.gradle`
- `gradle.properties`

## Apertura
Apri la cartella come progetto Android/Gradle in Android Studio o in un builder Android compatibile.
Poi esegui una build APK debug.

## Nota
La V6 contiene il core locale e l'interfaccia. Un motore video open-source esterno può essere collegato successivamente tramite API/endpoint configurabile.
